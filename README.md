# Touch Grass — JUET Outdoor Challenge

Touch Grass is a web application for students at Jaypee University of Engineering and Technology (JUET), Guna, designed to encourage outdoor activity through daily campus-focused challenges. Students can view the daily challenge, submit a photo as evidence, and track their progress, completions, streaks, and milestones. The project uses AI-assisted image verification to help review photo submissions.
